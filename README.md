# Newspaper_Structure
# 📰 Newsletter

A simple and clean **Newsletter Web Page** designed using **HTML and CSS**. This project presents a structured newsletter layout with a header, main content section, articles, images, an "In This Issue" sidebar, and a footer.

## 📌 About the Project

This project is a **static newsletter webpage** created using HTML5 and CSS3. The design is divided into different sections to make the content organized and easy to read.

The webpage uses a **two-column layout**, with the main content on the left and a blue sidebar containing an image and important newsletter topics on the right.

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and content of the newsletter.
* **CSS3** – Used for styling, colors, dimensions, borders, spacing, and layout.
* **Images** – Used to add visual content to the newsletter.

## ✨ Features

* 📰 Attractive newsletter-style header
* 🎨 Clean and simple color scheme
* 📑 Two-column content layout
* 📝 Main heading and article sections
* 🖼️ Image section for visual content
* 📋 "In This Issue" list for important topics
* 📐 Structured content using multiple `<div>` elements
* 🔲 Borders and separators for better organization
* 📱 Organized layout using CSS `float`
* 🦶 Separate footer section

## 🧩 Main Sections

### 1. Header

The header contains three sections:

* **NEWS** logo
* **LETTER** title
* Short description about the newsletter

### 2. Main Content

The left side contains:

* Main heading
* Two text columns
* Main content/image area
* Article section
* Article text and photo area

### 3. Sidebar

The right side contains:

* A large image
* **"In This Issue"** heading
* A list of current topics and updates

### 4. Footer

A separate footer is included at the bottom of the webpage to complete the newsletter layout.
